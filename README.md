# Publish the UniSathi preview

This folder is ready to publish as a static site. `index.html` opens the product preview, and `unisathi/` contains the WordPress theme.

## GitHub Pages

1. Create a new GitHub repository, for example `unisathi-preview`.
2. Upload the **contents** of this `outputs` folder to the repository root: `index.html`, `unisathi-preview.html`, and the `unisathi` directory.
3. In GitHub, choose **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and the `/(root)` folder, then save.
6. GitHub will show the public address, typically `https://YOUR-USERNAME.github.io/unisathi-preview/`.

The public static preview is for product presentation only. The actual contact form and WordPress features require a WordPress host and the `unisathi-theme.zip` theme package.
