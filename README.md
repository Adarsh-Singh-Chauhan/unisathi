## ✦ About UniSathi

**UniSathi** is a student-first campus safety and connectivity product concept. It brings students, parents, teachers, college administrators and campus support teams into one coordinated experience.

The project explores how attendance visibility, campus coordination, parent communication, transport workflows and safety support can be presented through a clear, role-based digital platform.

> **Product vision:** Every student. Every step. Connected.

## ✧ Core capabilities explored

- **Attendance visibility** — student attendance and teacher review workflows.
- **Campus check-in / exit** — concepts for authorised entry and exit records.
- **Parent communication** — relevant attendance, arrival and exit update concepts.
- **Emergency assistance** — an SOS interaction and proposed institutional response workflow.
- **Incident reporting** — structured reporting with authorised human review.
- **Transport coordination** — route, boarding and arrival workflow concepts.
- **Role-based workspaces** — distinct views for institutional and individual stakeholders.
- **Operational overview** — dashboards and reports for institutional coordination.

## ⇢ Safety-first workflow

The product concept is designed around a human-reviewed and institution-led response process:

```text
Student action / staff report
             ↓
Authorised verification and context review
             ↓
Configured responder queue and institutional procedure
             ↓
Policy-based guardian communication
             ↓
Restricted outcome record and audit trail
```

Safety-related reports should be reviewed by authorised people. Behavioural or sensitive allegations should never be treated as verified facts or automatically forwarded to guardians without appropriate review, policy and safeguards.

## ⓘ Prototype scope & responsible use

UniSathi is currently a **product-design and website prototype**, not a live emergency-response, surveillance or student-record system.

- Names, locations, attendance records, alerts, timings and dashboard metrics shown in the demo are illustrative.
- The demo does not contact emergency services, transmit a real student's location or notify a real guardian.
- The SOS interaction is a visual demonstration only.
- A production deployment would require authenticated role-based accounts, consent and permissions, secure data handling, notification providers, audit logs, institutional response procedures, security testing and applicable legal / privacy review.

Please treat the live links as demonstrations of the product experience, not as proof of operational services.

## 🚀 Run locally

### View the static experience

1. Clone the repository.
   ```bash
   git clone https://github.com/Adarsh-Singh-Chauhan/unisathi.git
   cd unisathi
   ```
2. Open `index.html` in a browser, or run a local static server.
   ```bash
   python -m http.server 8000
   ```
3. Visit `http://localhost:8000`.

### Install the WordPress theme

1. Package the `unisathi/` theme directory as a ZIP file.
2. In WordPress, open **Appearance → Themes → Add New → Upload Theme**.
3. Upload the ZIP, install and activate the theme.
4. Configure the homepage and any required WordPress settings.
5. Before public use, complete security, privacy, accessibility and deployment reviews.
